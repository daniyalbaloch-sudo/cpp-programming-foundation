# C++ Programming Foundation

A structured collection of C++ programs, algorithms, and mini-applications built to establish core programming logic, problem-solving skills, and procedural programming concepts.

---

## 📁 Repository Structure

### `01_syntax_and_basics/`
Focuses on fundamental language syntax, input/output operations, and data types.
* `cin_concept.cpp`: Console input processing and variable assignment.
* `first_programme.cpp`: Basic output formatting and syntax verification.

### `02_conditionals_and_logic/`
Covers decision-making structures, logical operators, and branching paths.
* `if_else_driving_license.cpp`: Evaluation using conditional logic trees.
* `university_admission_eligibility.cpp`: Multi-criteria eligibility assessment.
* `vowel_consonant_checker.cpp`: Character evaluation and logical grouping.

### `03_switch_case_apps/`
Menu-driven structures using switch control flow.
* `grade_system_switch.cpp`: Score-to-grade mapping logic.
* `simple_calculator.cpp`: Arithmetic operation dispatch using switch cases.

### `04_loops_and_iteration/`
Iterative control flow, counting loops, and condition-based execution.
* `for_loop_concept.cpp`: Counter-based iteration basics.
* `while_loop_table.cpp`: Dynamic multiplication table generator.
* `sum_and_factorial.cpp`: Accumulator pattern and mathematical processing.

### `05_arrays_and_matrices/`
Data structures, multi-dimensional indexing, and sequence traversal.
* `array_fundamentals.cpp`: Single-dimensional array declaration and iteration.
* `3d_array_practice.cpp`: Multi-dimensional array access and nested loops.

### `06_algorithmic_problems/`
Practical problem-solving scripts using basic C++ features.
* `highest_number_finder.cpp`: Linear scan algorithm to find maximum values.
* `password_verification.cpp`: Basic credential checking and loop-based retry logic.

### `07_main_projects/`
Full terminal-based applications combining all core concepts.
* `01_restoran_management_system/`: Menu display, quantity calculation, tax logic, and receipt generation.
* `02_upaisa_mobile_banking_app/`: USSD menu interface, balance tracking, load/transfer logic, and PIN verification.
